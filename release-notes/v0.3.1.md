# EB Recorder v0.3.1

EB Recorder v0.3.1 expands local Enhanced Broadcasting audio capture while keeping the original zero-extra-encoder design.

## Highlights

- Records the highest-resolution active Twitch Enhanced Broadcasting rendition.
- Reuses OBS's existing EB video encoder — no additional video encoder is created by the plugin.
- Selectable audio reuse: **Live**, **VOD**, or **Live + VOD**.
- Reuses the existing EB audio encoder(s) too — no additional audio encoder is created by the plugin.
- VOD-dependent choices follow the current OBS output settings. If a separate Twitch VOD track is unavailable, VOD choices are disabled and a stale saved selection falls back to Live.
- After a clean stop, writes per-track Matroska `BPS` metadata so Windows Explorer and compatible metadata readers can display AAC bitrate.
- Writes crash-resilient Matroska (`.mkv`) recordings to the current OBS recording directory.
- Optional automatic recording start with the EB stream.
- Automatic stop before the EB encoder pipeline is torn down.
- English and Russian UI.

## Performance and architecture

EB Recorder still does not create its own video or audio encoders. It attaches OBS's already-running Enhanced Broadcasting encoders to a local `ffmpeg_muxer` output.

The diagnostics dialog uses a 1-second coarse timer and only rebuilds UI state when something actually changes. With the dialog closed and automatic recording already started, there is no persistent EB Recorder polling loop.

The `BPS` metadata update runs only after a clean recording stop and does not remux or re-encode media packets.

## Fixes and polish

- Fixed `INSTALL.cmd` and `UNINSTALL.cmd` when run directly from a built source tree.
- Added VOD-aware audio-selection UI and automatic fallback to Live.
- Reduced unnecessary combo-box model updates in the diagnostics window.
- Removed unused audio-state bookkeeping and redundant encoder queries.
- Hardened EBML size parsing against integer overflow.
- Release archive naming now follows `VERSION.txt`.

## Tested with

- OBS Studio 32.2.2 x64
- Windows 10/11 x64
- Twitch Enhanced Broadcasting / Multitrack Video
- NVIDIA NVENC
- HEVC 2560x1440 60 fps TOP rendition
- AAC stereo 48 kHz / 160 kbps
- Live, VOD, and Live + VOD selection
- Windows Explorer audio-bitrate display after a clean stop

## Installation

1. Close OBS.
2. Extract `EBRecorder-v0.3.1-Windows-x64.zip`.
3. Run `INSTALL.cmd`.
4. Start OBS and open **Tools → EB Recorder**.

Existing 0.3.0 installations can be updated in place with the 0.3.1 installer.

## Important notes

This release is validated against OBS Studio 32.2.2. Future OBS changes to Multitrack Video encoder naming or lifecycle may require an EB Recorder compatibility update.

VOD and Live + VOD require OBS/Twitch to create the `multitrack video vod audio 0` encoder. Arbitrary local OBS audio stems are not currently supported.

Crash-resilient MKV remains the priority. If OBS or the system terminates abruptly, the optional final `BPS` metadata update may not run, but already-written Matroska media data remains independent of that metadata step.

EB Recorder is an independent community plugin and is not affiliated with or endorsed by OBS Studio or Twitch.
