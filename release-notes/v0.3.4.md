# EB Recorder 0.3.4 — recording reliability patch

## Changes

- Recording failures are now reported with the OBS error code and available error text.
- Stopping a recording with the diagnostics window closed now completes output cleanup and clean-stop MKV audio bitrate metadata automatically.
- Finalization waits for libobs to deactivate the output. Failed or forced recordings skip optional metadata changes; repeated Stop requests cannot mark a failure clean.
- Queued callbacks from a retired recording cannot affect the next recording or survive module teardown.
- Installer rollback preserves the previous installation when a directory rename fails, reports recovery failures, and retains existing backups.
- Windows CI now runs eight installer scenarios and headless libobs/Qt recording lifecycle regressions before packaging.
- New MSVC diagnostics remain visible without stopping the pinned third-party OBS SDK build.

The existing EB video and Live/VOD audio encoders are still reused; no additional encoder is created.

## Installation and recovery

Download `EBRecorder-v0.3.4-Windows-x64.zip`, close OBS, extract the archive, and run `INSTALL.cmd`.

If the installer finds `C:\ProgramData\obs-studio\plugins\eb-recorder.__old`, move that backup outside the OBS plugins folder (for example, to your Desktop), then run `INSTALL.cmd` again. Keep the backup until the new version is verified.

## Compatibility and validation

- Windows x64, OBS Studio 33+ plugin layout. OBS 32.x users should stay on v0.3.2.
- Built against the pinned OBS 32.2.2 SDK baseline.
- The patch's Windows Release build, package checksum, installer tests, and headless lifecycle tests passed CI before release preparation; versioned release assets are rebuilt and checked by the release workflow.
- The user confirmed successful installation and apparent operation of the patch build after moving an existing backup. This is a basic user smoke check, not a complete OBS-version, codec, GPU, or Live/VOD test matrix.

## По-русски

Исправлены обработка ошибок записи, завершение записи и BPS-метаданных при закрытом окне, а также откат установки при сбое переноса папок. Повторное нажатие Stop после ошибки не помечает запись как успешно завершённую. Дополнительные кодировщики не создаются.

Для установки закройте OBS, распакуйте `EBRecorder-v0.3.4-Windows-x64.zip` и запустите `INSTALL.cmd`. Если найдена папка `eb-recorder.__old`, переместите её из папки плагинов OBS, например на Рабочий стол, и повторите установку. Резервную копию сохраните до проверки новой версии.
