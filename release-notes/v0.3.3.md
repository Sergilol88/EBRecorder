# EB Recorder 0.3.3 — OBS Studio 33+ plugin installation

## Changes
- Updated the Windows release package to the official OBS Studio 33+ third-party plugin layout:
  - `eb-recorder/eb-recorder.dll`
  - `eb-recorder/data/locale/en-US.ini`
  - `eb-recorder/data/locale/ru-RU.ini`
- Updated the installer to replace older `bin/64bit` installations using its existing staging, validation and rollback strategy. An existing plugin configuration is not changed.
- Updated CMake packaging, Windows build output validation, English and Russian documentation, and portable OBS instructions.
- Kept existing Enhanced Broadcasting encoder reuse, Live/VOD audio, Matroska recording, and hotkeys unchanged.

## Compatibility
- **Target:** OBS Studio 33.x and newer, Windows x64.
- **OBS 32.x:** continue using EB Recorder v0.3.2; this release's flat plugin layout is not recognized by OBS 32.
- The build stays pinned to the proven OBS 32.2.2 SDK baseline because the relevant libobs encoder/output APIs and Twitch multitrack encoder names are unchanged in OBS 33.0.0.

## Verification before release
- [ ] Windows CI builds the v0.3.3 ZIP and SHA256 successfully.
- [ ] New ZIP has exactly one `eb-recorder.dll` in the plugin root, no legacy copy.
