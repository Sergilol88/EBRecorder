# EB Recorder v0.3.2

EB Recorder v0.3.2 adds native OBS hotkeys for starting and stopping EB Recorder without opening the plugin window.

## Highlights

- Adds **EB Recorder: Start recording** to OBS **Settings → Hotkeys**.
- Adds **EB Recorder: Stop recording** to OBS **Settings → Hotkeys**.
- Hotkeys use OBS's native frontend hotkey system; no global keyboard hook is added by the plugin.
- Hotkey bindings are stored by OBS in the current profile and reloaded when the OBS profile changes.
- Start hotkey uses the same TOP EB video and Live/VOD audio-selection logic as the plugin window.
- Stop hotkey performs the normal clean stop, including Matroska `BPS` audio-bitrate metadata finalization.
- Repeated Start while already recording and Stop while idle are ignored safely.
- The zero-extra-encoder architecture remains unchanged.

## Tested target

- OBS Studio 32.2.2 x64
- Windows 10/11 x64
- Twitch Enhanced Broadcasting / Multitrack Video

## Installation

1. Close OBS.
2. Extract `EBRecorder-v0.3.2-Windows-x64.zip`.
3. Run `INSTALL.cmd`.
4. Start OBS.
5. Open **Settings → Hotkeys** and assign keys to the two EB Recorder actions.

This version updates existing 0.3.1 installations in place.
